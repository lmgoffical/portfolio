# LMG Builds

Apps and websites I make vibe coding. Live at https://lmgoffical.github.io/portfolio/

The page is one file, `index.html`. A 3D scene (three.js, in `vendor/`) sits behind it and the camera
flies down a corridor as you scroll, stopping at one floating screen per project. Without WebGL, or
with reduced motion turned on, the same page shows as flat cards.

The request form saves to the `build_requests` table in Supabase.
